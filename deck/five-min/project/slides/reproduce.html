Limits and how to run it · the repo is public · Node 22 or newer

Run it yourself: five steps.

1 · get the packages

$ npm install

2 · find & replace, regex and the compiler, side by side · free, no API key

$ npm run demo

3 · the small potion: where is this input used? · free

$ node tool/mini-facts.mjs app-pill disableTooltip fixture/src

4 · Obelix and Asterix on the mission, three runs · costs API money

$ node bench/agent.mjs --runs 3

5 · the AngularJS app and its answer key · free

$ node scripts/generate-hybrid.mjs
$ node bench/hybrid.mjs --check

Where things are

tool/

the scripts: the potion

bench/

the measurements

scripts/

the test apps are made here

results/

every recorded run

Everything on these slides can be run again. Steps two and three need no model, so they are free. Step four starts the two real agents, so it costs API money: in our runs, between 6 and 65 cents for one agent. Step five builds the AngularJS app and checks that the script agrees with the answer key. Every run we recorded is in the results folder, so you can read the numbers without running anything.
