Win: nothing shouts when a count is off, and grep miscounts. Lesson: a tool that only lists direct uses leaves the agent to assemble the answer and buys nothing; once the compiler answers the whole question the bill is 3 to 5 times lower. Draw: Obelix scripts the labels too. Jobs 2 and 3 run on a different app, a routed admin of 105 components.

This is the slide for “is it only good for refactoring?”. Job 1: the grep agent misses string literals inside ternaries (60 instead of 100). Job 2 is the honest one: our first tool was written for the migration and did not help here; we added one command that walks “who renders whom” up to the routes, and then it did. Job 3: both lanes turn “icon → label” into a rule, so there is nothing for the compiler to add; say so.
