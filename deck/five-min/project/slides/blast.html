The wrong potion: no better than grep. The right one: under a third of the bill.

We asked which routes can show a shared component, on an app with 105 components. No edits, only answers. The potion made for the migration could list uses, but not routes. Asterix paid about the same as Obelix, and one run was wrong. We added two commands, where and unrouted. Then five runs of five were right, for six to eight cents. So the script must be able to answer the question you ask.
