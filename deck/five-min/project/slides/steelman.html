What if we only mention the compiler? · Claude Sonnet

A hint is not enough. A ready script is.

The hint added to the prompt

“The Angular compiler is installed in node_modules …
write your own migration script on top of the compiler and run it.”

Plain prompt

Obelix · files + grep

$0.17–0.32

a run · right in 8 of 8

3.3k–7.8k tokens written

Prompt + the hint

Obelix · his own codemod

$0.23–0.27

a run · right in 2 of 3

8.0k–10k tokens written

Prompt + ready script

Asterix · with the potion

$0.06–0.09

a run · right in 8 of 8 · once $0.65

0.5k–1.1k tokens written · once 11k

The fair objection: maybe the agent only needs to know the compiler is there. We told Obelix exactly that. He wrote his own codemod: two runs of three were right, one left 20 elements wrong. It cost as much as plain grep, and he wrote more: eight to ten thousand tokens of script each run. A second check: when the task did not say which input becomes which, both agents worked it out from the old source, three runs of three.
