Getafix’s potion

The Angular compiler is already in your node_modules

1

Facts from the AST

parseTemplate() gives exact spans; SelectorMatcher maps every element to its component the way the compiler does. Decoys fall away.

2

Changes as data

Rename, negate, map values, wrap in a pipe, move input to content, add imports: a small JSON spec the tool applies on exact spans, back to front.

3

Asterix decides, the potion judges

Asterix reads v2, writes the spec and resolves the “needs a decision” list. ngc, an AST diff and the built app check the result.

Asterix’s kit, ng-facts: about 600 lines of JavaScript on top of @angular/compiler, the engine Angular’s own ng update migrations are built on.

This is exactly how the Angular team ships migrations: schematics on top of NgCompiler. Ours is lighter — the recipe is JSON written by the agent, not code written by a human.
