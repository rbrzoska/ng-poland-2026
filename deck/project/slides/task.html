The task · PillComponent v1 → v2

Not a rename. A real API migration.

v1 — what the templates say→v2 — what they must say
[disableTooltip]="!isActive"→[tooltip]="isActive"
[disableTooltip]="count > 3"→[tooltip]="!(count > 3)"
variant="success"→tone="positive"
[variant]="a ? 'success' : 'warning'"→[tone]="a ? 'positive' : 'caution'"
[variant]="statusVariant"→[tone]="statusVariant | pillTone" + import
<app-pill label="Plain" />→<app-pill>Plain</app-pill>

Negate the meaning, remap values (also inside ?:), wrap fields in a pipe and import it, move an input into content. Touch nothing else.

Three kinds of change: a boolean flips meaning, an enum is remapped, an input becomes content projection. The pipe case needs a TypeScript edit too: imports array plus an import statement.
