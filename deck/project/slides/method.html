Read the small print before you quote us

How

  • Claude Code headless 2.1.294, claude-sonnet-5-5 and claude-haiku-5-5, 83 agent runs in all
  • same task text for both lanes; the tool lane gets one extra paragraph and no spec
  • lanes run one after another; every run is recorded and replayable
  • referees: ngc with strict templates, then the compiler’s AST compared with an answer key the generator builds on its own
  • every number is lowest–highest of the runs; nothing is averaged

What it does not show

  • the repos are synthetic and written by the tool’s author; no real codebase yet
  • one agent harness; three to eight runs per lane
  • the migration spec format covers exactly this kind of change
  • writing the tool is not on the bill; it rests on @angular/compiler, which is private API
  • agents trip: 16 of 83 runs lost minutes to a command of their own, in both lanes
If someone asks “did you cherry-pick?”: every run is in results/, the tables come from bench/evidence.mjs, and the one run where the tool agent cost more than the grep agent is on the race slide.
