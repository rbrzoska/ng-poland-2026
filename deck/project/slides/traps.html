Ils sont fous, ces Romains!

Four fortified camps around the village

Totorum

Same name, other component. <app-card [disableTooltip]> must not change.

Aquarium

Same name, not an input. A class field, @if (disableTooltip), a comment, a hint text.

Laudanum

Same prefix, other element. <app-pill-legacy> stays on v1. <app-pill\b matches it anyway.

Compendium

Text is not structure. A > inside count > 3, one attribute per line, templates inside .ts strings.

Every text-based script falls into at least one camp. An agent with grep does get out, by retrying against the compiler, and the retries are what you pay for. The Angular compiler walks past all four.

Each camp is a real trap in the workspace. Find and replace hits all four, a careful regex survives two: those are the two deterministic lanes on the race slide, both end with compiler errors. The grep agent ended functionally correct in every measured run, so do not claim it fails; it gets out by iterating against ngc. Only selector matching from the compiler never walks in.
