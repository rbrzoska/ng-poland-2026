We expected Obelix’s bill to grow with the repository. It does not: he writes a script, and a script does not care how many files it runs over. What the potion buys is a lower and steadier bill at every size, not a different growth curve.

This slide retires a claim we started with (“the agent types every edit, so output grows with the codebase”). Ratios are per pair, lowest to highest; a ratio below 1.5 is a run where the tool agent lost minutes to its own stray command.
