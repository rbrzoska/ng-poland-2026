Inside the cauldron

Four stages. We borrow three of them.

1

Parse

template → AST

parseTemplate() turns HTML and {{ }} into nodes with exact source spans. Expressions are trees too: !(a && b) is a PrefixNot, not a string.

→

2

Resolve

element → component

Decorator metadata plus SelectorMatcher: which component owns <app-pill>, which attribute is its input, which import puts it in scope.

→

3

Type-check

template → TypeScript

Every binding becomes a typed statement. ngc answers with NG8002 Can’t bind to ‘tooltip’, file, line and column included.

→

4

Emit

AST → ɵɵelementStart()

Ivy instructions the browser runs. The one stage we leave alone: the agent edits source, never output.

ng-facts

uses 1 + 2 to find every site; ngc runs 3 to judge the result; nobody touches 4. Careful: @angular/compiler is exported but private API, it may change in any release. Pin your Angular version.

Thirty seconds: Parse gives spans, Resolve gives ownership, Type-check gives a verdict. That is why ng-facts can stay at about 600 lines: it does not reimplement Angular, it asks Angular. Emit is the browser’s business. Angular’s public API document explicitly excludes @angular/compiler and covers only the command-line use of @angular/compiler-cli, so say “pin the version” out loud.
