The cauldron, explained to a legionary

A compiler is a reader that never skims

It reads structure, not characters

<app-pill is an element with a tag, attributes and a parent, not eight letters. count > 3 is a comparison, not a stray bracket.

It knows who is who

Every element is matched to the component whose selector claims it. [disableTooltip] on <app-card> is simply somebody else’s story.

It knows what a word means

Decorators say which attribute is an input, which is an output, what type it takes. A class field called disableTooltip is not an input, and the compiler knows it.

It tells you when you are wrong

700 errors before, 0 after. Not an opinion: a diagnostic with a code, a file, a line and a column. The perfect referee for an agent.

Obelix reads characters. The potion reads your app the way Angular will run it. We just ask it to share.

One minute, no jargon: a compiler reads the whole project the way the framework will execute it. Everything the agent struggled with on the traps slide — same name, other component; text that only looks like structure — the compiler has already resolved before it writes a single line of JavaScript.
